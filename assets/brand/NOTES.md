# Ellipse Hotels — Brand Analysis

Source: `assets/Ellipse-logo.pdf` (official lockup)

## Lockup

Horizontal mark:

1. **Symbol** — orange geometric building/line icon
2. **Wordmark** — “Ellipse” in white (or charcoal on light) brush script; orange flame/dot on the i
3. **Submark** — “HOTELS” in orange geometric sans, small caps under the script

Web exports (from PDF page render):

- `logo-on-light.png` — charcoal script + orange icon (for white headers)
- `logo-on-dark.png` — white script + orange icon (for navy heroes / footer)
- `logo.png` — same as on-dark

## Colour (from logo)

| Role | Value | Notes |
|------|--------|--------|
| Orange accent | `#E8722A` | Primary brand accent (logo icon + HOTELS) |
| Orange deep | `#C45A18` | Hover / darker accent |
| Charcoal script | `#1A1A1A` | Wordmark on light grounds |
| White | `#FFFFFF` | Wordmark on dark grounds |
| Navy (UI) | `#0A2540` | CTAs / footer authority |

Gold in earlier direction maps to this **orange** accent in the live logo.

## Photography

Property photography from ATG Paparazzi gallery (`ourpixo` / Ellipse Hotel Opening Day), stored under `assets/images/hotel/`.
Mapped in `data/images.js`.

## Typography

**Outfit** (UI/body) + **Cormorant Garamond** (selective display). Script from the logo is reserved for the logo itself — not used as site UI type.
